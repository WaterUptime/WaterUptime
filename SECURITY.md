# Security Policy

WaterUptime follows the organisation-wide [security policy](https://github.com/WaterUptime/.github/blob/main/SECURITY.md).

**Please do not report vulnerabilities in public issues.** Use the **Security** tab of the affected repository and choose **Report a vulnerability**:

- [Smart contract](https://github.com/WaterUptime/WaterUptime-SmartContract/security/advisories/new)
- [Frontend](https://github.com/WaterUptime/WaterUptime-Frontend/security/advisories/new)
- [This hub](https://github.com/WaterUptime/WaterUptime/security/advisories/new), for problems in documentation, such as guidance that would lead someone to expose personal data

Only maintainers can see these reports. We aim to acknowledge them within 5 working days.

WaterUptime is an experimental prototype on Stellar testnet. It is not approved for real funds, production water-service operations or personal data. The project's security and privacy assumptions are described in [docs/security-and-privacy.md](docs/security-and-privacy.md).
